# Customer-Churn-Prediction

A machine learning project designed to analyze customer data and predict the likelihood of customer churn. This project includes data preprocessing, model training, pipeline construction, and a web deployment layout (Streamlit).

## 📁 Repository Structure

```text
├── data/                  # Raw and processed datasets
├── models/                # Saved/serialized machine learning models (.pkl, .joblib, etc.)
├── src/                   # Source code for data preprocessing, engineering, and modeling
├── .gitignore             # Standard git ignore file
├── README.md              # Project documentation
├── main.py                # Main application script (e.g., Streamlit or execution pipeline)
└── requirements.txt       # List of required python dependencies
